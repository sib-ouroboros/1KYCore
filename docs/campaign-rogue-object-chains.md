## Обновление и проверки

Нужна пересобранная ветка. Штатный updater применяет существующие схемы visual-fields, state-animation и Padding, затем scene_templates08_05, gunpowder_conversation08_06 и rogue_objects08_07. SQL сначала проверяет зависимости и совместимость, затем добавляет отсутствующие строки; пользовательские данные не перезаписывает. Native GO с потерянными обязательными данными отклоняется. После прерванного обновления можно повторить импорт совместимого префикса. На MyISAM публикация идёт последней, без обещания транзакционной атомарности.

Локально прошли тесты фактического C++ AI и GameObject::SetLootState, 73 пакетов строк и24 пакетов актёров, согласованности всех текущих реестров. Изолированная MySQL8.0.45 проверяет первый/повторный/частичный импорт, конфликт каждого поля беседы, общих актёров, отсутствующие NPC/задания/цели, сцену/беседу с несовместимыми данными, сторонние SmartAI/заклинания/условия, visual-поля и per-spawn ScriptName. Контрольные суммы подтверждают сохранение спавнов и остальных таблиц. Схема удаляется после проверки; рабочий сервер не обновлялся.

CI: новый C++ тест входит в Reliability regression с ASan/UBSan; отдельный MySQL campaign-rogue-objects использует полный релиз и импорт кампаний. Эти проверки также включены в полный SQL-набор.
