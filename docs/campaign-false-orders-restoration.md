# False Orders: восстановление и текущий остаток

В ветке feature/ruRU-localization восстановлены модели/полные native templates
267492 и268458 и исходные addons (flags262144). Спавны map1220/phase8368,
задания45835/46324, их четыре цели, NPC AI и локализация не изменяются.

Модели15781, Lock2693, Map1220/Phase8368 подтверждены по пользовательским DB2;
BroadcastText51667 присутствует в подготовленной hotfix-базе. Нативный GOOBER
вызывает Player::KillCreditGO, а loader устанавливает нужный special flag
для целей GAMEOBJECT. Проверен настоящий C++-метод зачёта с тестовыми интерфейсами:
оба задания одновременно, две разные цели с одинаковыми StorageIndex0/1
в каждом задании, повтор, завершённое/неактивное задание и пустой журнал.
Это не игровая проверка всей цепочки или группового зачёта.

Event56349 не имеет исходных event_scripts/conditions, CPP-обработчика или
SmartAI в текущей базе. Его значение сохранено. SQL отвергает новые event_scripts,
SmartAI события, объекта и конкретного спавна до записи. Guard также защищает
QuestID, Type, ObjectID, Amount, StorageIndex, Flags/Flags2 всех четырёх целей,
полный template и addon. Пользовательские изменения не перезаписываются.

Для проверки в клиенте: обе цели заданий45835/46324, фаза8368, повтор,
использование в обратном порядке, один игрок и группа. Анимация, звук,
фазовая доступность и завершение всей сюжетной цепочки ещё не подтверждены.

## Остаток и новые результаты аудита

Осталось45 бесед,18 отсутствующих gameobject_template и53 существующие модели.
Весь остаток45 бесед заново классифицирован по точным зависимостям:
32 с отсутствующими UiCamera,17 с недостаточной исходной длительностью,
15 с packed-полями,5 с player-sentinel, одна с несовпадающей цепочкой.
Категории пересекаются. GUID source не используется исходной реализацией
и не считается причиной отказа. Подробности:
`audit-data/campaign-remaining-conversations-2026-10-05.json`.

Сверены все53 оставшиеся модели. Для252796/252800 клиентские модели и контейнеры
есть, но GAMEOBJECT_TYPE_GARRISON_SHIPMENT(45) не имеет native Use handler,
а Garrison::RewardWorkOrder нигде не вызывается. Одно SQL-восстановление
не обеспечит получение исследования; эти записи не объявлены исправленными.
Для этого нужен отдельный перенос механики с проверкой завершения work orders,
выдачи наград, условий, повторов, перезапуска и полного инвентаря.
Остальные блокеры перечислены в
`audit-data/campaign-remaining-models-2026-10-05.json`.

SQL рассчитан на штатный updater world; рабочий сервер не изменялся.
Реестр исходных данных и результатов тестов:
`audit-data/campaign-false-orders-restoration.json`.

Следующая группа266307/267003/268359 также проверена по SpellEffect: имеются
DUMMY-эффекты, событие56752 и дочернее заклинание230493. Наличие самого Spell ID
недостаточно; прежде чем восстанавливать эти модели, требуется разобрать
обработчики и дочерние события. Данные сохранены в сводном реестре моделей.

Все18 отсутствующих шаблонов также сведены в
`audit-data/campaign-remaining-templates-2026-10-05.json`. Для visual-полей
исходный код меняет эффекты при смене состояния, а некоторые — отдельно для
каждого игрока по visualQuestID. Наличие одноимённых клиентских полей в целевом
ядре ещё не позволяет заменить их addon.WorldEffectID без изменения смысла.
Проверка механики shipment также нужна для отсутствующих250899/250908.

MySQL8.0.45: прошли первое/повторное применение, восстановление после
прерывания, конфликты event/GO/spawn SmartAI, все7 защищённых параметров
каждой из четырёх целей, custom template/addon и отсутствующее задание.
246 других таблиц сохранили контрольные суммы; тестовая база возвращена
к исходному состоянию. C++-проверка зачёта также прошла локально.
