# Шестая группа: двери и книга кампаний

Восстанавливаются пять DOOR: 243490, 246287, 246535, 247329, 248466 и TEXT 240351. Итого шесть шаблонов, десять спавнов, шесть addon-записей и страница 5121. Источники и контрольные суммы те же, что в [пятой группе](campaign-fifth-restoration.md). Все шаблоны и спавны независимо перечитаны из исходного SQL, столбцы сверены с DDL настоящего release.

У выбранных дверей нет Lock, PlayerCondition, BroadcastText, скриптов или внешних действий. Сохранены исходные DOOR, состояния каждого спавна, флаги, фракции, Data8 (непрозрачность двери), Data9 (GiganticAOI) и Data2 (в том числе autoClose=300000 мс у 246287). Не заменяем их GENERIC и не меняем правила коллизий. Native GameObject::Use обрабатывает DOOR через UseDoorOrButton, а SetGoState обновляет коллизии. Полнота прохождения соответствующих кампаний этим не подтверждена; нужны проверки в клиенте, особенно проходов и фаз.

Для TEXT 240351 сохранены pageID=5121, language=0, pageMaterial=1, остальные Data=0. Название «Фолиант древних королей» обратимо восстановлено из UTF-8, ошибочно прочитанного как CP1252. В исходном SQL найден полный page_text 5121: NextPageID=0, PlayerConditionID=0, Flags=7, VerifiedBuild=21287. Текст страницы итальянский, начинается с «n questo tomo»; сохраняем его буквально, без исправления содержания и без выдуманного русского перевода. Русская локализация страницы требует отдельного достоверного источника. Клиентский запрос страницы обслуживается существующим HandleQueryPageText; AI сервера не менялся.

Миграция sql/updates/world/2026_10_02_00_world_campaign_doors_book.sql сначала создаёт временные копии, затем проверяет все конфликты GUID, поведения, addon, questitem и страницы. Отличающиеся Text (включая NULL и регистр), цепочка страниц, PlayerConditionID, Flags или VerifiedBuild прерывают импорт до любой постоянной записи. Осиротевшая локализация при отсутствующей основной странице также прерывает импорт, чтобы случайно не активировать чужой текст. Совместимые существующие строки сохраняются. Только затем добавляются отсутствующие page_text -> addon -> template -> spawn. Возможен повтор после прерывания сразу после страницы; произвольные ошибки MyISAM не становятся транзакционными.

Регрессия использует реальную release-базу в одноразовой MySQL 8: конфликты всех полей страницы, сохранность существующей страницы и остальных страниц, первичное восстановление отсутствующей страницы, прерывание после страницы и повтор, плюс прежние проверки всех групп. Пробы addon-конфликтов теперь вычисляются относительно исходного значения (XOR 1), а не предполагают, что flags=0/faction=114 всегда конфликтуют. Причина ошибки предыдущего CI — законные flags=0 у первого объекта пятой группы; SQL-guard корректно принимал совместимую запись.

После группы восстановлено 132/163 шаблона и 373/502 спавна. Осталось 31/129. Полный поштучный список с зависимостями: [campaign-pending-dependencies.json](audit-data/campaign-pending-dependencies.json). Проверены все 37 оставшихся после пятой группы записей исходного реестра.

Новая существенная зависимость: 245233 использует SmartGameObjectAI. В исходном Legion SQL найден event38 (получение SetData 1,1), action9 (открытие GO), target self; в нашей release записи нет. Шаблон и преграда пока не импортируются: необходимо найти и проверить отправителя события, перенести всю подтверждённую цепочку и проверить открытие в игре. Нельзя молча стирать AIName или импортировать закрытую преграду без обработчика.

Другие группы требуют Lock/PlayerCondition/Spell/SpellFocusObject/GarrShipment, проверки карты 1547, лута или неподдерживаемых полей исходной схемы. Для 247321 страница 5243 отсутствует даже в исходном SQL; для 252981 Spell=0, требуется реальный обработчик. Обычные войска оплота (250899/250908) не являются удалёнными ботами или наёмниками.
