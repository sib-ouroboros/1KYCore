# Модели15 существующих заготовок

Шаблоны250220–250234 используются перенесёнными спавнами декора археологии Даларана. В чистом release это DOOR type0 без модели и Data. В исходном Legion SQL это GENERIC type5 с моделями32910–32923/32111/32918 и Data1=1 (подсветка), без скриптов, заклинаний, условий, лута или квестовых предметов. Размеры копируются буквально, включая0.75 и0.87. Исходные и release-строки независимо перечитаны, никакие параметры не выдуманы. RequiredLevel отсутствует в исходной схеме: сохраняется0 из release, совпадающий с default целевого DDL.

Источники и контрольные суммы указаны в SQL и [расширенном аудите](campaign-placeholder-audit.md). Реестр полных исходных и baseline полей: [campaign-placeholder-model-restoration.json](audit-data/campaign-placeholder-model-restoration.json).

Миграция2026_10_02_01_world_campaign_placeholder_models.sql меняет только gameobject_template. Координаты, фазы, состояние и остальные поля спавнов не изменяются. Перед любыми постоянными записями проверяется наличие всех15 строк: каждая должна полностью совпадать с release-заготовкой либо с уже восстановленной исходной записью. Строки сравниваются по всем столбцам целевого DDL, текст — побайтно, включая регистр. Поэтому изменённые вручную название, модель, уровень, AI/ScriptName, Data или другие поля прервут импорт для ручного разбора, а не будут перезаписаны. Отсутствующие строки не создаются заново.

Также отвергаются addon с ненулевыми faction/flags/gold/WorldEffectID и квестовые предметы. Существующие нейтральные addon сохраняются; новые addon/questitem не создаются. Обновляются только строки, по-прежнему полностью совпадающие с baseline. Уже восстановленные строки остаются без изменений. Можно повторить импорт после восстановления любой части15 шаблонов; произвольные ошибки MyISAM не обеспечивают транзакционный rollback.

Реальная регрессия на одноразовой MySQL8 проверяет исходный release, первичное применение, все поля источника, сохранность всех спавнов и других таблиц/шаблонов, повтор, частичное применение, отсутствующую строку, изменение вручную до/после восстановления, все addon-поля и квестовые предметы. В тесте размеров учитывается округление FLOAT; SQL сравнивает реальные FLOAT со временными копиями того же DDL.

Из90 ранее найденных заготовок исправляется15, остаётся75 кандидатов на проверку. Это отдельный список: первоначальный реестр остаётся132/163 восстановленных отсутствующих шаблонов,31 шаблон и129 спавнов ещё ожидают разбора. Эти показатели не означают полноту всех кампаний. После импорта необходимо проверить отображение, масштаб и подсветку декора в клиенте26972. Общие NPC AI, питомцы и другие игровые механики не меняются.
