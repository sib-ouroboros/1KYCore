# Вторая группа восстановления объектов кампаний

Добавлены 36 шаблонов GENERIC (type 5) и 116 исходных спавнов.
Всего восстановлено 42 из 163 шаблонов и 151 из 502 спавнов.
В исходном реестре остаются 121 шаблон и 351 спавн.
Это учёт исходного аудита, а не состояние рабочей БД.

Источник шаблонов: LegionCore_world_735.26972_2024_10_23.sql,
архив SHA256 cf681e1fb2e7443daab2a5db04f4efa2fc53cc485ea8de6b6ec3d60d569c2696.
Источник спавнов: перенесённые кампании Sylvania на коммите
 a6145c22e9ad6ac69690d4a2f7794bae4e1caf95.
Координаты, фазы, модели и VerifiedBuild сохранены из источников.

У всей группы нулевые Data0..32, faction/flags/loot/questItem1..6,
специальные эффекты, SpellVisual/animation kits; AIName/ScriptName пустые.
В релизном дампе нет старых addon/quest-item записей для выбранных entry;
прямых ссылок на их ID в C++ не найдено. Исходный IconName сохранён,
в том числе questinteract у 252777, без добавления механики взаимодействия.

Новая миграция 2026_10_01_02_world_campaign_generic_objects.sql добавляет
только отсутствующие записи. Существующие совместимые шаблоны и спавны
сохраняются целиком. До постоянных записей проверяются принадлежность GUID,
несовместимые типы/скрипты/DataN и осиротевшие addon/quest-item зависимости.
Первая опубликованная миграция не изменена.

Обе группы проверяются регрессиями на настоящем релизном дампе в одноразовом
MySQL 8: первое/повторное/частичное применение, сохранение кастомизации,
отказ при конфликтах без изменений постоянных данных. Для второй группы
дополнительно сверяются исходные name/model/icon/size/build поля.

Список объектов: docs/audit-data/campaign-generic-restoration-2.json.
Общий учёт: docs/audit-data/campaign-restoration-status.json.

Восстановление записей не подтверждает завершённость игровых кампаний.
Видимость, модели DB2 и фазы необходимо проверить клиентом 26972.
Шаблоны с испорченными названиями, ненулевыми DataN/эффектами и другими
типами остаются для отдельного разбора. Рабочая БД и релизные архивы
не изменены; SQL применяет штатный обновлятор сервера.
