# Комплексный аудит Гилнеаса: пакет 10 октября 2026

Целевая ветка: `feature/npc-crowd-separation`. База аудита: опубликованный релиз,
исходники после `cc159cf`; это не снимок рабочей БД пользователя. Целевой клиент:
26972. Доступные локальные DB2/mmaps: 26654. Рабочий сервер не изменялся.

## Что доказано

* PASS (техническая проверка): 31 отдельный набор native C++ регрессий.
  Локально GCC, строгие предупреждения, без sanitizers; Linux CI запускает ASan/UBSan.
* PASS: новые SQL на изолированных копиях release world/hotfix базы MySQL8,
  повторное применение, сохранение пользовательских настроек и посторонних данных.
* PASS: 38 точек пяти исходных маршрутов Тобиаса, 33 внутримаршрутных коридора
  на локальном Detour. Прыжки между маршрутами, VMAP-пол и реальный spline не проверены.
* BLOCKED: запуск полного worldserver с реальными Linux данными и прохождение
  каждого задания обычным персонажем. Ни один квест не получает игровой PASS.
* Сборка новой ревизии проверяется отдельными GCC и Windows CI; результат запуска
  CI не равен успешной сборке. Актуальные результаты доступны во вкладке Actions.

## Изменения

Два C++ файла: `zone_duskhaven.cpp`, `zone_gilneas_city3.cpp`.
Общий движок движения, вычисление высоты, phase engine и боевой AI не изменены.
Native WaypointMovementGenerator передаёт индекс вектора с нуля, а не SQL point.
Исправлены только обработчики прибытия лошади 14465 и нетопыря 24920;
валидатор пяти маршрутов Тобиаса теперь требует все ожидаемые последовательные точки.

Миграции world:

1. `2026_10_10_01_world_gilneas_enemy_scaling.sql`: недостающий scaling у 11
   проверенных шаблонов, только map654. Границы5..20, faction, HP/damage и
   существующие custom scaling сохранены. Это не массовое уменьшение уровней.
2. `2026_10_10_02_world_gilneas_horse_action_xp.sql`: штатная способность68903
   только в пустом первом слоте horse36540; удаление только NO_XP_AT_KILL у
   четырёх проверенных rooftop-врагов. Формула XP остаётся native.
3. `2026_10_10_03_world_gilneas_genn_dialogue.sql`: первая реплика36332
   получает BroadcastText36340, вторая сохраняет36341. Пользовательская привязка
   и локализованные тексты не перезаписываются.
4. `2026_10_10_04_world_gilneas_tobias_native_routes.sql`: пять отсутствующих
   групп3850701..3850705, 38 оригинальных точек. Частичные/custom группы не
   дополняются: C++ использует существующий запасной маршрут при несовместимости.

Миграция hotfix:
`2026_10_10_00_hotfixes_broadcast_text_fr_dependencies.sql` — 13 настоящих
base BroadcastText132352..132363,132367 с текстами, emote/sound metadata из
проверенного 26972 SQL snapshot. Все13 SoundKit существуют в локальных DB2.
Существующие base rows и все locale rows сохраняются. Не маскирует ошибки логгера.

## Порядок ручной проверки и обновления

1. На отдельном тестовом сервере сделать резервные копии world/hotfix/characters;
   установить бинарники нового коммита. Рабочий сервер этим пакетом не обновлён.
2. Проверить DatabaseUpdater: новые world SQL применяются к world, hotfix SQL
   к hotfix. При отключённом updater применить в соответствующую БД вручную
   один раз и вести штатный ledger; не импортировать целую release БД заново.
3. Выполнить `contrib/tools/gilneas_live_world_audit.sql` в world и отдельный
   `gilneas_live_hotfix_audit.sql` в hotfix; сохранить output и полный startup log.
4. Создать обычного воргена, пройти всю цепочку от начала. Для каждой карточки
   записывать PASS/FAIL, уровень, фазу, GUID, XYZ, шаг до/после и видео сбоя.
5. Сначала24902,14465,14416,24920; затем все остальные карточки и прежние
   14336/14348/14368/14395/14399. Повторить проблемные scenes двумя игроками.
6. Для транспорта/escort: отмена и повтор, смерть, выход из vehicle, relog,
   уход из фазы/локации; чужая сцена не должна сбрасываться/давать credit.
