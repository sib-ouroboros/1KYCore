# Запись маршрутов для восстановления заданий

В игре администратором: `.wp record start`, пройти нужный маршрут, `.wp record stop`.
Команды требуют права WP_ADD и работают только в игровой сессии.
CSV `route-<GUID>-<время>.csv` сохраняется в рабочем каталоге процесса worldserver.
При запуске из `/opt/1kycore/bin` файл будет там; для systemd проверьте WorkingDirectory.
Начальная точка записывается сразу, последующие — раз в секунду при перемещении
на 0.5 м; финальная позиция сохраняется при остановке. Формат: номер, время в мс,
карта, экземпляр, X/Y/Z, ориентация. Десятичный разделитель всегда точка.
Запись завершается при выходе, смене карты/экземпляра, скачке более 50 м либо через час.
Каждая точка сбрасывается в файл; при аварии остаётся записанная часть.

Передайте CSV для проверки геометрии и переноса в подходящий формат пути.
Запись не изменяет NPC, задания или таблицы маршрутов автоматически.
Она не записывает паузы, прыжки и события как сценарные команды: их нужно
расставить отдельно при интеграции. Маршрут повозки 24438 пока не заменён.
