## Исправления native SceneMgr

OnSceneTrigger/Cancel/Complete передают callback копию SceneTemplate.
Скрипт может отменить сцену внутри callback: прежний указатель оставался
привязан к удалённому элементу карты. Terminal callbacks после этого читали
PlaybackFlags через недействительный указатель.

Завершение/отмена защищены по конкретному instance ID. Повторный вход из
современного или legacy callback не вызывает повторную выдачу награды или
бесконечную рекурсию. Оба штатных callback по-прежнему исполняются один раз,
и во время callback обычный lookup сцены остаётся доступным. Завершение
другого instance допускается. Scope guard снимает защиту при исключении.

Cancel packet на завершении не отправляется повторно, если callback уже
удалил instance. Запись удаляется перед снятием ауры. Снятие aura430 теперь
отменяет сцены по SceneId, а не все сцены с тем же PackageId. Явная отмена
по package сохраняется для своих прежних вызывающих методов.

Регрессия компилирует 14 настоящих методов SceneMgr и обработчик ауры:
современная/legacy отмена из callback, повторные terminal events, рекурсия,
вложенное завершение другой сцены, snapshot trigger, очистка ауры,
standalone SceneId0, отсутствующий пакет, исключение и общие package ID.
Проверка отмены чужой сцены воспроизводит отказ на предыдущем HEAD и
проходит после изменения. Локально GCC/Wall/Wextra/Werror/GLIBCXX_DEBUG;
CI запускает ASan/UBSan. Mock окружение не заменяет клиентский тест.
