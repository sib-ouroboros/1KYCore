# Зачёт сценарных событий SmartAI для цепочки245102

Добавлено новое действие250 `SMART_ACTION_SEND_EVENT_SCENARIO`.
Параметр1 — asset события, параметры2–6 должны быть нулевыми.
Игрок выбирается стандартным GetTargets; только игрок с активным Scenario
получает UpdateCriteria(SEND_EVENT_SCENARIO, event,0,0,player).
Переход в следующий шаг остаётся под контролем native Scenario/CriteriaHandler.
Существующие действия205/206/207 и их параметры не менялись.

250 выбран вне диапазона закреплённого LegionCore(END225), в пределах
SQL tinyint. У чистого релиза нет строк action_type250. Изменение не
переписывает SQL и не начинает выполнять исходные action205 как зачёты.
Неизвестные действия между прежним END и250 по-прежнему отвергаются
веткой default загрузчика; новые числовые значения требуют явной проверки.

Для рычага245102 подготовлен проверяемый черновик31 исходной строки.
Ровно три строки преобразованы:

| Исходный ключ(entry/source_type/id) | Событие | Перевод |
| --- | --- | --- |
|98771/9/5|47152|205(type92,event) ->250(event)|
|98836/0/5|47333|205(type92,event) ->250(event)|
|98836/0/9|47179|205(type92,event) ->250(event)|

Остальные28 строк, все события, тайминги, флаги, ссылки и цели сохранены.
Черновик — **REVIEW_ONLY_NOT_INSTALLABLE**, не SQL-обновление. Нельзя
импортировать его целиком без проверки NPC/заклинаний/маршрутов и сценария.
Транслятор прекращает работу при другом criteria type, пустом asset,
лишних параметрах, новых enum-конфликтах или неполной группе.

```powershell
python contrib/tools/campaign_lever_smartai_draft.py --output lever-draft.json
python contrib/tests/test_campaign_lever_smartai_draft.py
python contrib/tests/test_smart_scenario_event.py --compiler c++
```

Последняя проверка компилирует реальные ветки исполнения250 и205 и новую
ветку валидации. Она проверяет три asset, двух игроков, NPC, игрока без
сценария, пустой/null список целей, освобождение списка, все лишние параметры
и неизменность освещения205. Это тест с интерфейсами движка, поэтому отдельно
запускаются полные Linux/Windows-сборки и существующий тест реальной
Player::UpdateCriteria/Scenario::CanUpdateCriteriaTree с санитайзерами.

Для завершения цепочки остаются оба маршрута NPC98836 (98836/9883600),
реплики98771, ссылки на заклинания/зачёты, обработка активации GOOBER
в native action9, контекст телепортации1522 и изоляция игроков. Нужно
подтвердить соответствующие критерии/шаги сценария в целевых DB2 и выполнить
guarded SQL с тестами конфликтов. Ни рычаг, ни NPC этой цепочки пока не
активированы новым пакетом. Остаток40 бесед,11 шаблонов,43 модели сохраняется.
Рабочий сервер не меняется.
