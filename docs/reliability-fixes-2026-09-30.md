# Исправления устойчивости панели и подготовки персонажа

## Версия сборки

`genrev.cmake` раньше требовал достижимый тег `init`: при его отсутствии даже
обычный Git checkout получал `unknown 1970-01-01 ... (Archived)`. Теперь
`git describe --always` позволяет использовать 12-символьный хеш без тегов,
включая shallow checkout CI. Дата берётся из коммита, ветка — из Git;
при detached HEAD отображается `HEAD`, а изменённое отслеживаемое дерево имеет `+`.
Сохранена совместимость с репозиториями, где тег `init` есть. Сравнение кеша CMake
теперь точное и учитывает дату, поэтому символы имени ветки не интерпретируются как regex.

После обновления исходников повторите конфигурацию CMake и сборку. Специально
загружать теги для определения версии больше не нужно. Исходный архив без `.git`
не содержит достоверной ревизии: он по-прежнему обозначается как Archived.
Для намеренной сборки архива есть `-DWITHOUT_GIT=ON`. Если Git недоступен или
отказывает в доступе к checkout, это отдельно отражается в диагностике.

## Канал команд панели

- Неполные заголовки и тела TCP-сообщений остаются в буфере до следующего чтения.
  Обрабатываются несколько сообщений за одно чтение. Предел входящего тела — 1024 байта.
- Принимаются существующие сообщения с завершающим NUL и сообщения без него.
  Внутренний NUL и превышение длины закрывают соединение. Размер заголовка не менялся.
- Строка строится по точной длине, ручной `new[]` удалён. Очередь исходящих буферов
  владеет значениями, поэтому закрытие соединения не оставляет выделенные сообщения.
- Устранено двойное увеличение размера ответа после MessageBuffer::Write.
  Ответ, не помещающийся в 16-битный размер, закрывает соединение с диагностикой,
  вместо обрезания размера и отправки повреждённого буфера. Постраничная выдача
  большого списка аккаунтов потребует отдельного изменения протокола/клиента.
- Перед выполнением проверяются типы и диапазоны JSON-полей. Ошибка отдельной
  команды не прерывает обработку следующей. Неправильный JSON больше не пишется
  целиком в журнал, где он мог содержать пароль создаваемого аккаунта.
- Отсутствующий/null `talent` сохраняет прежнее значение 0. Допустимы 0..3 и 255.
  Дробные числа, строки и boolean вместо целочисленных идентификаторов отклоняются.

Существующий допуск подключения по IP и смысл команды authorization не менялись.
Эти изменения не являются переработкой системы авторизации панели.

## Инвентарь

Очередь экипировки хранит GUID и целевой слот. Между шагами подготовки предмет
может быть перемещён или удалён: перед надеванием он заново ищется у игрока.
Удалённые, переданные, уже экипированные и перенесённые в банк предметы пропускаются.
Перемещённый между инвентарными сумками предмет обрабатывается по текущей позиции.

Выдача сумок проверяет наличие шаблона 21876 и все четыре слота. Занятые слоты
сохраняются. При нехватке места или отказе экипирования дальнейшая выдача прекращается.
Уже созданная, но не надетая сумка остаётся у игрока.

Старая очистка рюкзака в полной административной подготовке не расширялась и не
удалялась. Обычная смена специализации без полной подготовки — отдельная задача.

## Проверки

Workflow Reliability regression запускает настоящую генерацию CMake на временных
Git-репозиториях без тегов, с init, с грязным деревом, shallow/detached checkout
и на архиве. Сетевые тесты используют реальные MessageBuffer и встроенную JsonCpp,
тела изменённых методов и AddressSanitizer/UBSan. Проверяются разделение каждого
кадра в разных местах, объединение сообщений, границы размеров, плохие типы JSON
и продолжение после исключения. Отдельный тест проверяет исчезновение/перемещение
предметов между шагами и ошибки выдачи сумок. Полные сборки дополняют эти тесты;
игровой запуск сервера ими не заменяется.
