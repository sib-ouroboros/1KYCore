# Четвёртая группа восстановления объектов кампаний

Добавлены 25 шаблонов GENERIC (type 5), 60 исходных спавнов и 25 addon-записей.
Итог исходного аудита: 88 из 163 шаблонов и 273 из 502 спавнов восстановлены;
остаются 75 шаблонов и 229 спавнов. Рабочая БД этим отчётом не измеряется.

Шаблоны: LegionCore_world_735.26972_2024_10_23.sql из архива SHA256
cf681e1fb2e7443daab2a5db04f4efa2fc53cc485ea8de6b6ec3d60d569c2696.
Спавны: кампании чернокнижника и охотника на демонов Sylvania,
коммит a6145c22e9ad6ac69690d4a2f7794bae4e1caf95. Все 25 шаблонов и
60 строк спавнов повторно прочитаны из источников и сверены по всем
переносимым полям с реальной схемой релиза. В исходном релизе нет
addon/quest-item записей для выбранных entry. Числовое совпадение 249793
в boss_noura_mother_of_flames.cpp относится к заклинанию, а не объекту.
Прямых ссылок на entry этих gameobject в C++ не найдено.

У 19 объектов Data3=1 (GiganticAOI) и flags=32 (GO_FLAG_NODESPAWN).
Проверены GameObjectData.h, SharedDefines.h, ObjectMgr::LoadGameObjectTemplateAddons,
создание GameObject и ветка GO_JUST_DEACTIVATED. Флаг считывается из addon
и поддерживается ядром. Шесть остальных объектов имеют нулевые DataN и flags.
Все они без скриптов, quest/condition ID, специальных эффектов и лута;
названия Fel Chest/Loot Stack сами по себе не превращают GENERIC в сундук.

Для пяти названий исправлено ошибочное чтение UTF-8 как CP1252. Преобразование
обратимо на уровне байтов, не является переводом или придуманным названием:
Пиратский флаг, Древко флага, Кружка, Ритуальный круг, Свечи.
Исходные и исправленные строки сохранены в name_corrections реестра.
Пустое имя 246424 сохранено из источника; штатный GENERIC не требует имени.
Модели, размер, все Data0..32, VerifiedBuild, координаты и фазы сохранены.

SQL 2026_10_01_04_world_campaign_generic_addons.sql сначала проверяет все
конфликты: чужой GUID, тип/DataN/скрипты, quest-item зависимости, несовместимые
faction/flags/gold/WorldEffectID. При существующем шаблоне без addon файл
отказывается работать, чтобы не менять его прежние флаги автоматически.
Совместимые существующие шаблоны, addon и спавны сохраняются целиком.
Для отсутствующих записей порядок: addon, затем шаблоны, затем спавны.
Поэтому прерывание после addon оставляет проверяемые исходные значения,
и повторное применение может восстановить недостающие шаблоны.
Это не транзакция с откатом при произвольной ошибке БД.
Ошибка с _1kycore_generic_guard означает конфликт, который следует выяснить
по данным сервера и этому реестру; удалять кастомизацию для обхода проверки нельзя.

Регрессия на одноразовом MySQL 8 и настоящем релизе проверяет все четыре
группы, точные исходные поля, повторное применение, сохранение кастомизации,
защиту от конфликтов. Для этой группы дополнительно проверяются отсутствие
addon у существующего шаблона, изменение flags/faction/gold/WorldEffectID,
неизменность остальных addon и прерывания после addon и после шаблонов.
Предыдущие опубликованные SQL не изменены. Новый SQL готов для штатного
обновлятора; рабочая БД и релизные архивы не менялись.
