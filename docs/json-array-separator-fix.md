# Проверка разделителей JSON-массивов

В bundled Reader::readArray проверка одновременно требовала tokenArraySeparator и tokenArrayEnd. Два разных типа не могут совпасть, поэтому ошибочный разделитель не отклонялся. Например, `[1 2 3]` мог быть принят как `[1,3]`: токен 2 уже прочитан, но не добавлен и не признан ошибкой.

Теперь допустимы только запятая или закрывающая скобка: ошибочен токен, который не равен ни одному из них. Обработка корректных массивов, вложенности и уже разрешённых комментариев сохранена. Регрессия компилирует настоящие json_reader/json_value/json_writer с ASan/UBSan, проверяет сохранность значений корректных массивов, пустые и вложенные массивы, комментарии, пропущенные и неправильные разделители, trailing comma и успешный разбор после ошибок. Отдельные особенности старой библиотеки, например принятие данных после корневого значения, этим исправлением не меняются.
