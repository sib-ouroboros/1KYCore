# Гилнеас: задания 14204, 14159 и 14375

Исправления рассчитаны на клиент Legion 7.3.5 (26972). Они сохраняют
сюжетную сцену, где Лорна стреляет в превратившегося Джосайю Эвери:
обязательный бой игрока с ним не добавлен.

## Что изменено

- 14204: команда 67805 запускает обычный бой пса со скрытнем, раскрывает
  цель и сбрасывает мешающие атаке состояния следования. Дополнительный
  `MoveCharge` после `AttackStart` убран. Обработчик заклинания работает
  также при выборе штатного `PetAI`; общий выбор AI не изменён.
- Команда не требует выбранного вручную NPC: поиск целей остаётся за
  штатными эффектами заклинания. Обработчик принимает только пса 35631
  и живую цель 35463 при незавершённом задании у владельца.
- Скрытень остаётся пассивным для остальных игроков. Ответный бой и поиск
  игроков в прежнем радиусе 2 м разрешены только при статусе `INCOMPLETE`.
  После потери этого условия текущим противником включается возврат домой.
  Таймер ярости больше не переполняется при вычитании.
- При завершении/отмене 14204 удаляется именно квестовый пёс 35631;
  обычные питомцы других entries не удаляются.
- 14159: наградное заклинание 67352 остаётся единственным штатным запуском
  призыва. Скрипт повторяет его только для БД, где оно отсутствует в награде.
  Триггер выбирает Эвери, призванного конкретным участником, а не ближайшего
  Эвери другого игрока. Тело сохраняется 5 секунд после выстрела.
- 14375: неправильный ID оков 69169 заменён на 69196 (`In Stocks`), уже
  используемый в другом скрипте этого ядра. При сдаче снимаются оковы,
  сюжетное обездвиживание и только флаг запрета поворота, а не всё поле flags2.
  Затемнение 94053 ограничивается 3 секундами; переход в фазу 68481
  выполняется событием самого игрока. Исчезновение NPC не отменяет событие.
- Вход в игру после сдачи 14375 восстанавливает переход только в исходной
  зоне сцены (карта 654, area 4786). Остальные зоны и несдавшие задание
  персонажи не затрагиваются.

## Источники и пределы проверки

Сравнены исходники
[AshamaneCore](https://github.com/AshamaneProject/AshamaneCore/tree/master/src/server/scripts/EasternKingdoms/Gilneas)
и [ArkCORE-NG](https://github.com/Arkania/ArkCORE-NG/blob/master/src/server/scripts/EasternKingdoms/Gilneas/zone_gilneas_city1.cpp).
Они содержат близкие реализации и часть тех же ошибок; перенос готового
чужого исправления не выполнялся. Проверен опубликованный world-дамп
1KYCore: награда 14159 содержит 67352, 14375 — 68639; привязки C++ AI
пса, скрытня, короля и сценического триггера присутствуют. Наградное
заклинание 68639 не изменено.

`contrib/tests/test_gilneas_quests.py` компилирует настоящие функции
проверки квеста, команды пса, ответной атаки, снятия оков, отложенного
перехода, восстановления при входе и награды Эвери. Тестовые сущности
заменяют серверное окружение; это не эмуляция клиентских визуальных эффектов,
нанесения урона, DB2-выбора ближайшей цели или всей сцены. SQL-тест на
реальном релизном дампе проверяет первый/повторный импорт привязки 67805
и сохранение остальных привязок и таблиц.

Перед признанием сцен полностью соответствующими оригиналу необходимо
прохождение на клиенте 26972: без выбранной цели и с выбранным скрытнем;
реальный урон/зачёт убийства; отсутствие нападений без задания;
отмена/завершение задания в бою; два игрока в одной фазе; один выстрел
Лорны и видимое тело Эвери; трёхсекундное затемнение, движение/поворот после
освобождения и повторный вход во время перехода. Полное совпадение визуальных
таймингов с Blizzard пока не заявляется.

Для применения команды пса нужны одновременно новая сборка и файл
`sql/updates/world/2026_10_01_01_world_gilneas_attack_lurker.sql`.
Рабочая БД и релизные архивы этой правкой не изменяются.
