## Адаптации и изменения поведения

- Сохранён обработчик WorldToDiscord из нашей ветки: upstream удаляет потребителя очереди, оставляя её заполнение в chat_log.cpp. Без адаптации при включённой функции сообщения накапливались бы без отправки.
- Новый `--update-databases-only` выходит после создания RAII-обработчика StopDB, чтобы соединения корректно закрывались.
- Upstream включает межфракционный аукцион по умолчанию (`AllowTwoSide.Interaction.Auction = 1`) и обновляет выбор аукционного дома. Явно заданное значение 0 в действующем конфиге сохраняет запрет межфракционного аукциона.
- Русский README, оформление 1KYCore и workflow публикации БД рабочей ветки сохранены. В main оформление соответствует upstream.
