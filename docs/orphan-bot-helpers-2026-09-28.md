# Удаление неиспользуемых помощников ботов — 28.09.2026

База изменений: `628c10df6ba4c079d9d8e592ec941cc5f5720362`. Сборки этой версии GCC, Clang и Windows завершились успешно.

## Удалено

- Неиспользуемые функции BotUtility: специальные аренные ауры, изменение заклинаний, подбор рангов, поиск позиции, перемещение питомца и старые вспомогательные операции с предметами.
- BotAIHorrorState и отключённый ProcessHorror. В действующем UpdateAI вызов ProcessHorror был закомментирован; таймер не выполнял действий. UpdateAI теперь явно пустой.
- Не вызываемые методы принудительного движения BotMovementAI, построения и применения путей.
- Редактор маршрутов AIWaypointsMgr: создание/удаление/перемещение визуальных точек, запись описаний и редактирование связей. Соответствующие команды были удалены раньше.
- Три подготовленных SQL-запроса записи маршрутов и их идентификаторы. Данные таблиц не изменяются.
- Неиспользуемые определения тактик, дистанций, аренных аур и закомментированный блок их создания в SpellMgr.

## Что сохранено и почему

BotMovementAI всё ещё назначается обычным игрокам и обслуживает модификаторы урона в подземельях. Оба обработчика урона сохранены побайтно.

BotUtility::FindItemFromAllBag и StoreNewItemByEntry используются обычными игроками и пользовательскими меню. Их действующие реализации сохранены побайтно; добавлены прямые заголовки ObjectMgr и ItemEnchantmentMgr.

Даларанская арена использует точки aiwaypoints 72/73. Загрузчик, поиск точки, SQL SELECT и использование координат сохранены. Этот пакет не заменяет маршруты NPC и не удаляет таблицу aiwaypoints. Оставшиеся поля загрузчика и его прежняя проверка AUTO_INCREMENT требуют отдельного переноса, поэтому здесь не менялись.

Настройки и протокол ToolSocket, PlayerBotSetting, базовый PlayerAI/UnitAI, NPC AI, вход персонажа, обычный страх/контроль и защита старых аккаунтов остаются прежними. Несколько записываемых настроек ботов пока сохранены для последующей согласованной очистки административного интерфейса.

## Проверка

Поиск ссылок выполнен по всем 2584 отслеживаемым файлам src. Удалённые API не имеют оставшихся активных ссылок. Сверены семь сохранённых функций: два обработчика урона, две операции с предметами, загрузчик/поиск/instance маршрутов. Их реализации совпадают с исходными. Проверены неизменность Dalaran Sewers, CharacterHandler, Unit.cpp, PlayerBotSetting, OnlineMgr и UnitAI, наличие новых прямых заголовков и git diff --check.

Локальная компиляция и игровой запуск не выполнялись. После публикации требуется проверить GitHub Actions. Для игровой проверки остаются вход обычного персонажа, модификаторы урона в подземелье, выдача/экипировка предметов через меню и старт Даларанской арены за обе команды.
