- `2026_10_02_03_world_campaign_client_validated_objects.sql`: пять дверей, два фокуса заклинаний, один фазовый объект и четыре портала; 12 отсутствующих шаблонов, 12 исходных размещений и12 addons. Перечень и клиентские доказательства находятся в JSON-манифесте.

Два маршрута уже есть в релизе и сохраняются, два отсутствующих добавляются с VerifiedBuild0, поскольку оригинальный SQL не содержит номера сборки.

## Проверка и защита данных

Локальная папка dbc/enUS предоставлена владельцем сервера. Проверены WDC1-структуры и LayoutHash по текущему DB2Metadata.h, наличие моделей, Map, Phase, Lock, PlayerCondition, SpellFocusObject, Spell и FactionTemplate. Хеши файлов и проверенные ID записаны в манифестах; исходные клиентские бинарники в репозиторий не добавлены. Совпадение LayoutHash не доказывает номер сборки клиента.

Все проверки совместимости выполняются до первой записи постоянных таблиц. Существующие совместимые шаблоны, addons и маршруты сохраняются; конфликт останавливает импорт. Для двух заглушек разрешены только полностью совпадающие исходные базовые или уже восстановленные строки. Произвольные изменения администратора не перезаписываются. Порядок записи допускает повтор после прерывания: маршруты, addons, шаблоны, отсутствующие размещения. Это не обещание транзакционного rollback для MyISAM.

Регрессионные проверки расширены для реального MySQL8: конфликты до записи, сохранение сторонних строк и VerifiedBuild, правильный индекс эффекта, повторный импорт и частичное применение. До публикации выполнены независимое повторное чтение оригинальных шаблонов/размещений, проверка целевого DDL, исходных ссылок и синтаксиса Python. Результат новых MySQL-проверок следует смотреть в Actions; локальный MySQL не запускался.
