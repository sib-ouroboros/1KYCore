## Исправление создания беседы

Первая строка4304 (9822) — пауза4000мс, BroadcastText0, без эффектов/анимаций.
Источник выбирает conversation_actor и не читает одновременно имеющуюся
conversation_creature с player sentinel. Поэтому actor slot0 пуст. Native Create
раньше отклонял сцену до отправки клиенту. Теперь отсутствие актёра допускается
только для строки без текста, SpellVisualKit, AnimKit, SpeechType, камеры,
callback-флагов и opaque padding, с нейтральными animation60/60. Если тот же
индекс используется другой строкой с текстом, актёр по-прежнему обязателен.
Неизвестная клиентская строка также отклоняется. Пауза остаётся в исходной цепочке.
