# Выбор цели для Foul Stream у тёмных шаманов

В boss_korkron_dark_shaman.cpp отрицательное число -20.0f передавалось
в uint32 position метода SelectTarget. Преобразование отрицательного float
в беззнаковое целое выходит за представимый диапазон; первый выбор цели
работал некорректно и мог уступать запасному варианту.

Исправлен один вызов: position=0, dist=-20.0f. По контракту UnitAI.h
и реализации DefaultTargetSelector отрицательная дистанция исключает
ближнюю зону. Сохраняется фильтр игроков без Toxic Mist; если такой цели
вне 20 единиц боевой дистанции нет, остаются прежние два запасных выбора:
любой игрок без Toxic Mist, затем любой игрок. Таймер и заклинание неизменны.
Дистанция включает native IsWithinCombatRange, а не только расстояние центров.
Перенос -20 в dist восстанавливает выраженное этим значением намерение;
точный розничный алгоритм случайного выбора не подтверждён игрой на сервере.

Тест test_dark_shaman_target.py извлекает настоящий блок события и
настоящий DefaultTargetSelector::operator() из исходников. Проверяет дальнего
игрока, границу 20, оба запасных пути, отсутствие игроков, исключение питомцев,
ауру Toxic Mist и повторное планирование события. Порядок кандидатов
детерминирован вместо случайной выборки; полный ThreatManager не моделируется.
Компиляция строгая, с ASan/UBSan и проверкой float-cast-overflow.

Остальные боссы, общий AI, обычные NPC и питомцы не изменяются.
